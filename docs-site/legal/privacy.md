## Data the service stores

- Account data: email address, a password hash, optional two factor enrolment and sign-in history.
- Project data: names, branding, webhook addresses, API key hashes and audit events.
- Payment data: references, amounts, currencies, status, an optional customer reference, an optional customer email and metadata that your application supplies.
- Provider data: provider credentials are sealed at rest and are never shown again. Provider payment identifiers are stored with attempts.
- Technical data: IP addresses and user agents in the audit log and in rate limiting, and request logs.

The service does not store card numbers. Card details go to the card provider.
