What your customers can pay with

Turn methods on per project. The pay page offers the ones you enabled.

Lightning
Settles instantly.Your own LND node, or the platform node if you have none.
On-chain Bitcoin
A fresh address for every attempt.Confirmations are counted for you, and short payments can be topped up on the same address.
Card through Revolut

How it works

One payment object from first request to receipt.

  1. Create a payment

    Send an amount and a reference with an idempotency key, so a retry never charges twice.

    curl $GW/v1/payments -H "Authorization: Bearer $KEY" \
  -H "Idempotency-Key: order-123" \
  -d '{"reference":"order-123","amount":1800,"currency":"EUR"}'

  2. The customer pays

    Send them to the hosted pay page, embed it in an iframe, or draw your own screen from the API.

  3. Your app is told

    A signed webhook arrives once the payment settles, with three days of retries if your server is down. The receipt link is on the payment.
